# Pi workspace instructions

This repository is a dedicated workspace for Pi itself: building Pi extensions, keeping Pi prompt/config experiments, and saving resumable Pi sessions.

Before planning or making changes in this repository:

1. Read `docs/PI_KNOWLEDGEBASE.md` completely.
2. For Pi features, read the installed Pi docs relevant to the change before implementing:
   - Extensions: `docs/extensions.md`
   - Skills: `docs/skills.md`
   - Prompt templates: `docs/prompt-templates.md`
   - Themes: `docs/themes.md`
   - TUI: `docs/tui.md`
   - SDK: `docs/sdk.md`
   - Sessions: `docs/sessions.md`
3. Keep reusable Pi findings, conventions, and decisions in `docs/PI_KNOWLEDGEBASE.md`.

Do not copy project-specific rules or domain knowledge from other repositories into this workspace.
